# 제휴상품 마진 관리

오토바이 리스 옵션상품(헬멧·블랙박스·액션캠 등)의 **마진·손익분기·가격 인상 영향**을 계산하는 웹페이지입니다.
설치할 프로그램이나 서버 없이, 파일을 올리기만 하면 됩니다.

- **신규 상품 검토**: 조건을 넣으면 임원 보고용 미니 보고서가 바로 만들어집니다. 단품·세트, 365일·180일을 지원합니다.
- **등록 상품**: 제휴사별 시트와 가격 인상 시뮬레이션을 제공합니다.
- **비교 시트**: 상품마다 1안·2안·3안을 나란히 비교합니다. 인상 후에도 마진을 지키는 일리스료를 계산합니다.

---

## 폴더 구성

```
tayota-margin-app/
├─ index.html               ← 앱 본체 (화면·계산 전부)
├─ config.js                ← 설정 (팀 공용 저장을 쓸 때만 수정)
├─ firestore.rules          ← 팀 공용 저장 보안 규칙 (Firebase용)
├─ data/products-seed.json  ← 등록 상품 초기 데이터 7개
├─ .nojekyll                ← GitHub Pages가 파일을 그대로 쓰게 하는 빈 파일
└─ README.md                ← 이 설명서
```

> ⚠️ **저장소는 반드시 비공개(Private)로 만드세요.** `data/products-seed.json`에 실제 매입 조건이 들어 있습니다.
> 공개 저장소로 올리려면 이 파일을 빼고 올린 뒤, 앱의 "JSON 가져오기"로 따로 넣으세요.

---

## 1단계 · 내 PC에서 먼저 열어 보기 (1분)

1. 폴더 안의 `index.html`을 더블클릭하면 크롬이나 엣지에서 열립니다.
2. 이 상태에서는 **내 브라우저에만 저장**됩니다. 제목 옆에 "이 브라우저에만 저장 중"이라고 표시됩니다.
3. 이 방식으로는 "기본 데이터 불러오기"가 동작하지 않습니다. 브라우저 보안 때문입니다.
   **등록 상품 → 전체 요약 → JSON 가져오기**를 누르고 `data/products-seed.json`을 선택하세요.

## 2단계 · GitHub에 올리기 (5분, 코딩 필요 없음)

1. <https://github.com>에 로그인합니다.
2. 오른쪽 위 **＋ → New repository**를 누릅니다.
3. 아래처럼 입력하고 **Create repository**를 누릅니다.
   - Repository name: `tayota-margin` (원하는 이름)
   - **Private** 선택
4. 만들어진 화면에서 **uploading an existing file** 링크를 누릅니다.
5. 이 폴더 안의 파일과 `data` 폴더를 **통째로 끌어다 놓습니다.**
   - `.nojekyll`처럼 점으로 시작하는 파일은 숨김 파일이라 안 보일 수 있습니다. 빠져도 동작에는 문제없습니다.
6. 아래 **Commit changes**를 누르면 끝입니다.

## 3단계 · 웹 주소로 열기 (둘 중 하나)

### A. GitHub Pages
1. 저장소 → **Settings → Pages**로 이동합니다.
2. **Source: Deploy from a branch**, **Branch: main / (root)**를 고르고 **Save**를 누릅니다.
3. 1~2분 뒤 `https://<아이디>.github.io/tayota-margin/` 주소가 생깁니다.

> 비공개 저장소에서 Pages를 쓰려면 GitHub 유료 플랜(Pro/Team 이상)이 필요합니다. 회사 플랜을 확인하세요.
> 또 Pages 주소는 **누구나 접속할 수 있는 공개 주소**입니다. 데이터는 4단계 로그인으로 보호하세요.

### B. Cloudflare Pages (비공개 저장소도 무료)
1. <https://dash.cloudflare.com>에 가입하고 **Workers & Pages → Create → Pages → Connect to Git**을 누릅니다.
2. GitHub를 연결하고 이 저장소를 고릅니다.
3. 빌드 설정은 모두 비워 두고(Framework: None) **Save and Deploy**를 누릅니다.
4. `https://tayota-margin.pages.dev` 같은 주소가 생깁니다.
5. (선택) **Zero Trust → Access**에서 회사 이메일만 접속하게 막을 수 있습니다.

## 4단계 · 팀 전체가 같은 데이터 보기 (Firebase, 15분)

1~3단계까지만 하면 각자 브라우저에 따로 저장됩니다. 팀원이 **같은 등록 상품과 비교안**을 보려면 무료 Firebase를 연결합니다.

1. <https://console.firebase.google.com>에서 **프로젝트 추가**를 누르고 이름을 정합니다(예: `tayota-margin`). Google 애널리틱스는 꺼도 됩니다.
2. **빌드 → Authentication → 시작하기 → 로그인 방법 → Google → 사용 설정**을 하고 저장합니다.
3. **Authentication → 설정 → 승인된 도메인**에 3단계에서 받은 주소를 추가합니다.
   - 예: `아이디.github.io` 또는 `tayota-margin.pages.dev`
4. **빌드 → Firestore Database → 데이터베이스 만들기**를 누르고 위치는 `asia-northeast3 (서울)`을 고릅니다.
5. Firestore → **규칙** 탭에 `firestore.rules` 파일 내용을 그대로 붙여 넣습니다.
   - `example[.]co[.]kr` 부분을 **회사 이메일 도메인**으로 바꾸고 **게시**를 누릅니다.
6. **프로젝트 설정(톱니바퀴) → 내 앱 → 웹(</>)**에서 앱을 등록하면 `firebaseConfig` 값이 나옵니다.
7. GitHub에서 `config.js`를 열고 연필 아이콘으로 수정합니다.
   ```js
   window.APP_CONFIG = {
     firebase: {
       apiKey: "복사한 값",
       authDomain: "프로젝트ID.firebaseapp.com",
       projectId: "프로젝트ID",
       appId: "복사한 값"
     },
     allowedDomain: "회사도메인.co.kr"
   };
   ```
   **Commit changes**를 누르면 1~2분 뒤 사이트에 반영됩니다.
8. 사이트를 열고 **Google 계정으로 로그인**을 누릅니다. 회사 계정으로 로그인하면 제목 옆에 "공용 저장소 연결됨"이 표시됩니다.

## 5단계 · 기존 데이터 넣기 (한 번만)

1. 로그인한 상태에서 **등록 상품 → 전체 요약 → 기본 데이터 불러오기**를 누릅니다.
2. 등록 상품 7개가 팀 공용으로 들어갑니다. 이미 있는 상품은 건너뛰므로 여러 번 눌러도 중복되지 않습니다.
3. 정기적으로 **JSON 백업 내려받기**를 해 두세요. 문제가 생기면 **JSON 가져오기**로 복원합니다.

## 무엇이 어디에 저장되나요?

| 내용 | Firebase 연결 시 | 연결 안 했을 때 |
|---|---|---|
| 등록 상품 · 비교안 · 확정 여부 · 목표 마진율 | 팀 공용 (실시간 공유) | 내 브라우저 |
| 입력 중인 검토 조건 · 임시 시나리오 | 내 브라우저 | 내 브라우저 |

## 계산 기준 (요약)

- 매입원가 = 소비자가 − (소비자가 × 할인율 + 추가 할인) + 배송비. 세트는 구성품 공급가를 더합니다.
- 판매금액 = 일리스료 × 리스 일수(365 또는 180) × 수량
- 마진 = 판매금액 − 손실·수수료 − 매입가액, 마진율 = 마진 ÷ 판매금액
- 손익분기 수량 = 고정비 ÷ 대당 마진(올림)
- 기준안 마진율 유지 일리스료 = 인상 후 매입원가 ÷ (리스 일수 × (1 − 기준 마진율))
- 부가세와 자금조달 이자는 반영하지 않습니다.

## 수정하고 싶을 때

- 화면과 계산은 모두 `index.html` 한 파일에 있습니다. GitHub에서 연필 아이콘으로 고치고 Commit하면 반영됩니다.
- 큰 변경은 Claude에게 이 파일을 주고 요청하면 됩니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 로그인 버튼을 눌러도 아무 일이 없음 | 브라우저 팝업 차단을 해제하고, Firebase "승인된 도메인"에 사이트 주소가 있는지 확인 |
| "공용 데이터를 불러오지 못했습니다" | `firestore.rules`의 도메인이 로그인한 계정과 같은지 확인 |
| "기본 데이터 불러오기"가 안 됨 | `data/products-seed.json`이 올라갔는지 확인. 아니면 "JSON 가져오기"로 직접 선택 |
| 팀원 화면에 데이터가 안 보임 | 팀원도 같은 회사 도메인 계정으로 로그인했는지 확인 |
